# Conversor de Temperatura — Java

Este projeto converte uma temperatura informada em graus Celsius para Fahrenheit e Kelvin.

## Objetivo
Praticar lógica de programação e fundamentos da linguagem Java.

## Tecnologias
- Java JDK

## Execução
javac ConversorTemperatura.java
java ConversorTemperatura
